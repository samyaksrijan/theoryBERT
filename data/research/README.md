# Recorded local validation

These small reports were produced by the actual local validation runs on 23–24 October 2026. They are included so a hosted clone can display the measured limited rule baseline and the tiny random-BERT smoke checks. They describe the recorded run, not the hosting server hardware, a deployed model checkpoint, or pretrained-model research accuracy.

The 20% semantic equivalence measurement is 8 of 40 shipped test descriptions. Unsupported rule predictions count as incorrect. No trained pretrained checkpoint or model weights are included. A fresh local report under `artifacts/` takes priority over these recorded reports.
